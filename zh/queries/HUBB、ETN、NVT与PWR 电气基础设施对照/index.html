    HUBB、ETN、NVT与PWR 电气基础设施对照¶

    更新时间：2026-06-01 CEST（currentness guardrail；对照分类仍有效，价格/action 需看各实体或 fresh snapshot） 问题：同样是 data-center / grid / time-to-power 受益，HUBB、ETN、NVT、PWR 到底是不是同一种生意？

    状态：本页保留为 electrical-infra taxonomy / comparison checkpoint，不作为四家公司当前买点页。HUBB/ETN/NVT/PWR 的 fresh action 需回到各实体、follow-up ledger 或新市场快照。

    结论先行¶

    不是同一种生意。当前更合理的分类是：

    Ticker 本质层级 当前证据强度 估值状态 动作
    HUBB grid / electrical delivery compounder + NSI bolt-on 已有 FY2025 + Q1 2026 + NSI acquisition/term-loan，本地证据最完整 Fwd PE ~24.3x；质量 premium 但新增 USD3B M&A / debt gate deep-dive / pullback discipline；需 NSI close/pro forma refresh
    ETN broad electrical platform issuer-primary 证据已补齐；data center + utility + modular power + liquid cooling 均成立 Fwd PE ~28.6x；EV/EBITDA ~27.9x comparison anchor / pullback reserve
    NVT rack power / enclosures / liquid-air cooling / connections issuer-primary 证据已从产品层升级到 backlog/segment 层 Fwd PE ~35.1x；P/FCF ~72x watch-only；等 monetization / 回撤
    PWR EPC / grid / large-load-center delivery issuer-primary 证据已补齐；是工程交付瓶颈，不是设备商 Fwd PE ~51.6x；EV/EBITDA ~44.3x bottleneck real / no-chase

    第一性原理拆分¶

    数据中心建设的电气侧可以拆成四件事： 1. 能不能接上电网 / 输配电扩容：PWR 更靠近工程交付，HUBB/ETN 有设备与组件内容。 2. 园区和楼内如何配电：HUBB、ETN、NVT 都有产品暴露，但 ETN 更平台化，HUBB 更偏 grid/electrical delivery，NVT 更靠近 enclosure / connection / rack power。 3. 高密度机柜如何散热：NVT 和 ETN 的 cooling/liquid-cooling 证据更直接；HUBB/PWR 不是主冷却平台。 4. 谁承担执行风险：PWR 承担 labor / EPC / claim / schedule 风险最大；设备商则更多承担产能、产品 mix、客户集中和价格风险。

    单名判断¶

    HUBB¶

    HUBB 的优点是本地证据已经闭合：Q1 2026 中 Grid Infrastructure、data-center electrical demand 与 765kV 机会已经进入 deep-dive bucket。缺点是当前不是显著低估，仍要等更舒服的 USD430-470 或 EPS/order 证据继续上修。

    ETN¶

    ETN 原先是 wiki 里的对照锚但缺本地证据；现在 issuer-primary 缺口已补。它的强点是平台广度与 recent acquisitions：Fibrebond 增强 modular power enclosure，Boyd Thermal 增强 critical liquid cooling。弱点是估值已经把“电气平台稀缺”定价得很满。

    NVT¶

    NVT 的证据层比之前强：10-K/10-Q 把 Systems Protection、data-center mission-critical applications、liquid/air cooling、Electrical Products Group 和 backlog growth 串起来。现在的问题不是“方向是否真实”，而是当前估值下的兑现速度是否足够。

    PWR¶

    PWR 应该进入 active browse layer，因为它不是 passing mention。它直接暴露在 electric grid、transmission/substation/distribution 和 large load center 电气/机电交付。它的瓶颈属性真实，但估值和 contractor economics 要强行压住仓位冲动。

    当前补充后的 wiki 缺口¶

    • 已补：ETN entity、PWR entity、NVT issuer-primary raw、四者对照 query。
    • 仍缺：ETN/PWR 的 earnings-call 级 order/backlog 细节；如果后续要做买点，不应只靠 10-K/10-Q。
    • 仍缺：NVT 对 hyperscaler / data-center 收入占比的更精确拆分；当前只足够支撑 watch-only。
    • HUBB：需要窄更新，不再只是等 Q2 order / margin / Grid Infrastructure gate。2026-05-04 NSI acquisition 与 2026-05-15 term loan 是新的资本配置与 leverage 变量：业务上增强 Electrical Solutions / datacenter / network infrastructure breadth，财务上引入 USD3B purchase price、cash/debt financing、closing/regulatory 与 integration risk；维持 deep-dive / pullback discipline。
