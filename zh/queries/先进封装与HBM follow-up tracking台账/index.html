    任务定义¶

    Batch 1 只跟踪一条硬瓶颈链：

    AI accelerator demand → HBM stack → CoWoS / SoIC / 2.5D / 3D packaging → substrate / ABF / FC-BGA → TCB / hybrid bonding → inspection / metrology → probe / test / KGD → materials / purity

    核心问题不是“谁在 AI 链上”，而是：

    1. 哪些指标能证明瓶颈仍紧；
    2. 哪些公司级证据能从行业逻辑落到订单、收入、毛利、客户或产能；
    3. 哪些名字只是高质量 anchor，哪些还有 hidden-alpha research payoff；
    4. 当前价格是否允许行动，避免把 bottleneck truth 误写成 buy-now。

    PDFS AP&T process-control / OSAT data layer 中高：Exensio 覆盖 fab/test/assembly；OSAT product 面向 outsourced semiconductor assembly/test；Intel Advanced Packaging and Test page 直连 AP&T；CIM300 提 backend packaging assembly/test equipment；Q1 2026 revenue $60.1m (+26% YoY), backlog $246.4m USD 66.88，距 1Y intraday high -6.7%；fresh bands 39/45/52/59/67/72 source-backed HERMES hlines / no-chase above 59 AP&T/OSAT revenue mix、客户扩散、margin durability；未闭合前不升 buy-now
    Resonac package-substrate materials / CMP slurry / die-bonding / high-purity gases 中：official R&D page 支持 package-substrate base materials、CMP、die-bonding films、high-purity fluorine gases；AI/HBM monetization 未闭合 JPY 18,680，距 1Y high -4.0% materials reference / no-chase package-materials revenue/order/customer proof、价格回撤

    Lane-level 指标¶

    lane 必跟指标 为什么重要 证据最低门槛
    HBM stack HBM3E/HBM4 volume、ASP、share、customer qualification 判断 HBM 不是一次性 tightness，而是结构性 mix 迁移 issuer-primary 或 customer-primary；不能只用 sell-side headline
    CoWoS / SoIC / 2.5D / 3D capacity additions、lead time、utilization、margin、balance timing 判断 packaging 是否仍是 GPU 交付瓶颈 TSMC transcript / annual report 原文复核；区分 capacity 与 actual output
    Probe / test / KGD probe-card demand、DRAM/HBM test mix、known-good-die bottleneck HBM 堆叠前后必须提高测试强度 revenue/order 明确连到 HBM 或 AI compute test
    Substrate / ABF / FC-BGA AI package substrate utilization、pricing、capacity digestion、customer hidden alpha 主要在 execution discount 是否收敛 公司级订单/产能/毛利，不只行业 ABF 需求

    Per-ticker tracking checklist¶

    Anchors / comparators¶

    TSM¶

    • 复核 TSMC Q2 2024 transcript 原文：CoWoS tightness、capacity more-than-doubling、balance timing 的上下文。
    • 记录 CoWoS / SoIC / 3DFabric capacity addition 是否仍紧，还是进入 capacity digestion。
    • 跟踪 advanced packaging margin / pricing 口径；不要把 foundry leading-edge demand 自动等同于 packaging margin upside。
    • 若只得到行业媒体复述，不升级 action。

    MU¶

    • 跟踪 HBM3E / HBM4 volume production、HBM revenue mix、ASP / margin。
    • 区分 Micron-primary 的 H200 linkage 与 NVIDIA/customer-primary confirmation。
    • 观察 DRAM cycle 是否吞掉 HBM mix benefit。
    • 股价贴近高位时只做 HBM benchmark，不写 fresh buy。

    SK hynix¶

    • 跟踪 HBM3E / 12-layer HBM3E 供货、HBM4 timing、客户集中度。
    • 观察 MR-MUF / TSV / thermal execution 是否继续领先。
    • 估值与拥挤度高时只做 HBM leader anchor。

    Samsung¶

    • 2026-07-07 Q2 guidance 记录为 memory-cycle confirmation：合并 sales KRW 171T、op profit KRW 89.4T、OPM 52.3%；只作为 sector validator，不升级 HBM proof。
    • 必须拿到客户认证或实际出货证据，才从 challenger 升级。
    • 跟踪 HBM3E 12H / HBM4 ramp、yield、thermal route。
    • 若仍停留在 development / sampling / planned production，维持 proof-needed。

    Probe / test / KGD¶

    FORM¶

    • 更新每季 DRAM revenue、Probe Cards revenue、DRAM YoY、HBM wording。
    • 寻找 HBM absolute revenue、HBM3E/HBM4 probe-card qualification、客户扩散。
    • 检查 gross margin 是否跟随 HBM mix 改善，而非只靠 memory capex beta。
    • 估值 >50x forward P/E 或 P/S ~12 附近，不写 buy-now；只在 pullback + proof 同时出现时升档。

    COHU¶

    • 跟踪 HBM inspection metrology design wins 是否转为订单/收入。
    • 验证 FY2026 HPC revenue outlook USD 80-100M 是否兑现。
    • 观察 EPS / margin 修复；若仍只有 outlook 而无利润，维持 proof-first。
    • 小盘弹性不等于 thesis closed。

    Inspection / metrology / process control¶

    CAMT¶

    • 跟踪 Hawk / tier-1 HBM / AI IDM orders 的发货节奏。
    • 看订单是否从单一客户扩散到多客户。
    • 若 revenue 与 backlog 未跟上，降为 high-quality watch。
    • 估值 premium 时只做 pullback-only，不因 HBM 订单追价。

    ONTO¶

    • 跟踪 Dragonfly G5 / 3Di 的 double-digit commitments 是否转 revenue。
    • 跟踪 HBM4 ramp 客户是否持续追加订单。
    • 区分 technical qualification 与公司级 revenue acceleration。
    • 若 2026 Dragonfly platform growth >50% 未兑现，降档。

    Equipment / TCB / hybrid bonding¶

    BESI¶

    • 跟踪 orders、revenue、book-to-bill 中 hybrid bonding / 2.5D AI computing 贡献。
    • 寻找 HBM/AP 量产 adoption、客户平台、份额证据。
    • 若只是技术位置正确但份额不明，维持 premium watch。
    • 贴近 high 时 no-chase；旧 €180-190 buy zone 需用 fresh snapshot 重算。

    ASMPT¶

    • 跟踪 C2S TCB additional orders 是否转 revenue / backlog。
    • 核验 C2S POR / sole supplier、C2W AOR、HBM4 12H/16H 的最新 issuer-primary wording。
    • 检查客户集中度与平台切换风险。
    • 近高位不追；只有订单兑现 + 回撤才考虑升为 active candidate。

    OSAT / advanced packaging services¶

    AMKR¶

    • 跟踪 Advanced Products revenue、2.5D/3D TSV、SiP、test mix。
    • 跟踪 Arizona advanced packaging/test facility ramp 与 TSMC Phoenix collaboration。
    • 检查 capex、折旧、毛利压力；确认它不是 CoWoS owner。
    • 若只是 reshoring story、无客户/利润兑现，维持 pullback-proof。

    ASX¶

    • 跟踪 FOCoS、FOCoS-Bridge、2.5D/3D、CPO 与 AI/HPC/HBM-adjacent revenue。
    • 跟踪 packaging / testing capex ROI 与 computing revenue mix。
    • 平台龙头不是 hidden；贴近高位维持 no-chase anchor。

    Substrate / ABF / FC-BGA¶

    AT&S¶

    • 重点跟踪 Kulim / Leoben ramp、utilization、capex、客户透明度。
    • 检查 AI accelerators / HBM / CoWoS / EMIB / large complex substrates 是否转成财务证据。
    • 判断 execution discount 是错杀还是合理风险。
    • 旧 €65-72 buy zone 与 EUR 102 current context 差距大；下一步必须刷新 zone。

    Ibiden¶

    • 跟踪 data-center MPU / AI GPU substrate demand 与 Electronics capex。
    • 检查 margin 与 utilization 是否支撑 benchmark 溢价。
    • 市场已理解其位置；除非大回撤或新客户/产能证据，不升 hidden。

    Unimicron¶

    • 跟踪 FCBGA / AI Server / Switch / ASIC 订单与收入 mix。
    • 跟踪 substrate / computers 高占比下的 margin 与产能。
    • 旧 residue 中 business case 最强，但当前估值不便宜；只等 pullback + proof。

    Nan Ya PCB¶

    • 跟踪 high-end server / 800G switch / enterprise SSD 是否继续兑现。
    • 跟踪 ABF roadmap 对 AI servers / ASIC / next-gen switches 的收入化。
    • 下一季重点看订单、毛利、产能 utilization。
    • 已明显 rerate；无回撤不写 fresh buy。

    Materials / process subsystems¶

    ENTG¶

    • 跟踪 advanced packaging / HBM / 2.5D / 3D materials、CMP、cleans、contamination-control 的收入归因。
    • 检查 AI-related demand 是否进入公司级 sales / margin，而非只停留在材料复杂度叙事。
    • 纪律：USD 128-138 才是旧 accumulate-on-weakness；USD 145-155 是 no-chase study zone；需 fresh snapshot 更新。

    MKSI¶

    • 跟踪 laser drilling、chemistry、blind micro-via、package substrate 与 AI packaging 的收入拆分。
    • 检查 Atotech / broad platform 的债务、周期与毛利压力。
    • 贴近高位时不升 active；只有 substrate revenue proof + valuation reset 才升档。

    升级 / 降级触发器¶

    升级触发器¶

    lane / 名字 升级条件
    TSM CoWoS / SoIC transcript 原文确认 tightness、capacity expansion、pricing/margin 或 balance timing；且不是媒体二手概括
    MU / SK hynix HBM volume、ASP、margin、客户确认继续上修；HBM4 roadmap 与份额更清楚
    Samsung customer qualification / actual shipment 闭合，而非 sampling
    FORM HBM absolute revenue 或 HBM4 probe-card qualification 披露；DRAM/HBM mix 推动 margin；估值回撤
    COHU HBM inspection / HPC test 订单转收入，USD 80-100M HPC outlook 兑现，EPS 修复
    CAMT / ONTO 新 HBM / AI packaging 客户扩散，订单转 revenue，估值 reset
    BESI / ASMPT TCB / hybrid bonding 订单持续、进入 HBM/AP 量产、份额更明确；股价不在垂直高位
    AMKR / ASX advanced packaging capex 明确转 revenue / margin；客户和 mix 更清楚
    AT&S / Unimicron / Nan Ya AI server / ASIC / switch substrate 客户、产能、utilization、margin 同时改善；回撤后赔率恢复
    ENTG / MKSI AP/HBM revenue attribution 或 margin read-through 变直接，且估值不再 premium

    降级触发器¶

    lane / 名字 降级条件
    TSM CoWoS tightness 原文不支持，或 capacity balance 提前、pricing/margin 无弹性
    HBM anchors HBM ASP / margin 下滑，客户认证延迟，HBM share 低于预期
    FORM / COHU / TER bucket HBM/test 只剩 broad memory cycle beta，客户/订单不再扩散，毛利不跟
    CAMT / ONTO / NVMI bucket qualification / order 不转 revenue，客户集中，valuation 继续扩张
    BESI / ASMPT 订单一次性、HBM/AP 量产 adoption 不清，份额被竞争稀释
    OSAT advanced packaging revenue 增长被折旧/capex/低毛利吞掉
    Substrate 客户不透明、Kulim/Leoben 或产能 ramp 延迟、margin 不改善、ABF price 下行
    Materials / MKSI 仍只有“复杂度提升”泛化叙事，不能量化收入或利润

    价格 / 估值纪律¶

    1. 任何 action band 必须来自 dated market snapshot；无 snapshot 不写 buy/add/trim。
    2. 2026-05-14 snapshot 结论：这不是 cheap catch-up basket；大量名字贴近 52w high 或已经 vertical rerating。
    3. 旧 packet buy zones 只能作历史纪律参考，不能直接沿用：AT&S、BESI、Ibiden、Unimicron、ENTG、MKSI 等都需 fresh zone refresh。
    4. 当前默认动作：
    5. no-chase anchors：TSM near high、MU、SK hynix、ASX、BESI、Ibiden、Unimicron、AT&S、MKSI。
    6. pullback / proof：FORM、CAMT、ONTO、AMKR、ENTG、Samsung。
    7. proof-first：COHU、ASMPT、Nan Ya PCB 以及更小 substrate / test optionality。
    8. 只有满足 证据升级 + 估值回撤/重置 + fresh snapshot 三项，才可从 watch 升为 active buy candidate。
    9. 价格纪律不能反向证明 thesis；便宜需要解释为什么不是 thesis 破坏，贵需要解释还剩多少 margin for error。
