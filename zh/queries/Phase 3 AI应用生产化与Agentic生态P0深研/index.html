    Phase 3 AI应用生产化与Agentic生态P0深研¶

    更新时间：2026-06-06 CEST 关联：DOCN与INOD AI应用基础设施二阶重估研究线（内部维护页，未公开） · 科技主线研究ticker统一台账（内部维护页，未公开） · 什么值得买（内部维护页，未公开） · 企业软件平台 current-live 两批写回台账（内部维护页，未公开）

    结论先行¶

    这轮 deep research 的结论比最初 P0 更收紧：Phase 3 不是“所有 AI-adjacent 便宜股”，而是 AI 从模型/训练/capex 转向 production 后，谁控制 agentic 系统最难绕开的失败点。

    最终我把名单分成四类：

    层级 名字 当前判断
    Core discussion VRNS 最干净的 AI data permission / DSPM 控制层；但必须证明 Atlas / AI security attach 不是 SaaS conversion 幻觉。
    P0- / current actionable CVLT 当前 risk/reward 最可执行，可小仓；但它是 AI-era resilience hedge，不是 AI 原生控制层。
    P0- / control-plane candidate PEGA agent workflow 逻辑对，但 Q1 revenue -10% 与 NOW/CRM/MSFT capture 风险要求等待底部修复。
    P0- / high-beta implementation GDYN AI revenue 29.3% 是硬证据；但仍是服务/实施经济学，不能写成平台控制层。
    P0- / domain ops EXLS / G 应补入 Phase 3 框架：行业数据、决策流程、agentic operations last-mile。
    Tactical TASK INOD-like HITL/evals/safety 高赔率，但 AI 替代与 BPO 拖累并存；没有底部不买。
    Observation BLZE / BOX BLZE 是 AI object storage 暗线但 proof 不够；BOX 是 content control-plane 候选但 MSFT/GOOG bundle 风险太大。

    Phase 3 定义：AI application productionization / agentic ecosystem¶

    Phase 1 是模型能力；Phase 2 是训练算力、GPU、HBM、网络、电力、机房 capex；Phase 3 是企业和开发者把 AI 放进真实产品、流程、数据和客户交付系统。

    Phase 3 的真实预算流向不是“再买一个 AI feature”，而是：

    1. agent / AI app 跑在哪里；
    2. agent 能访问哪些企业数据；
    3. 输出和动作如何被评估、审计、回滚；
    4. 业务流程如何闭环；
    5. 人在哪里兜底；
    6. 模型、代码、artifact 和 skill 如何被治理。

    DOCN / INOD 的共同点是它们都被旧标签压低：DOCN 从 SMB/developer cloud 变成 AI-native cloud benchmark；INOD 从 data/BPO 变成 AI data lifecycle / evals benchmark。它们不是同一业务，但证明市场正在从 AI capex winners 扩散到 AI utilization / productionization winners。

    产业链层级¶

    1. Workflow / system-of-action control plane¶

    agent 真正进入企业，不是停在聊天窗口，而是要触发 case、审批、规则、例外处理和审计。PEGA 是这里的候选，但必须证明 Blueprint AI 能转成 ACV/RPO/收入再加速，否则会被 NOW/CRM/MSFT 收编。

    2. Permission / security / recovery / governance¶

    这是最刚性的预算层。agent 一旦能访问数据，就必须解决权限、暴露面、审计、恢复、回滚和勒索后的业务连续性。VRNS 是 data permission / DSPM 控制层；CVLT 是 resilience / recovery 层。

    3. Domain operations / HITL / data lifecycle¶

    企业 AI 不会一夜全自动。数据工程、行业 workflow、human-in-loop、AI safety、model maintenance、异常处理会继续存在。GDYN、EXLS、G、TASK 都在这层，但经济学差异很大。

    4. Content / storage substrate¶

    AI 增加内容和数据量，但 storage/content 层最容易被 hyperscaler、MSFT 365、Google Workspace、Cloudflare R2、DOCN 等 bundle 和价格竞争挤压。BLZE 与 BOX 保留观察，但不作为核心 P0。

    最终P0排序¶

    1. VRNS — 核心讨论资格最高，但买点等 reset / reclaim。
    2. CVLT — 当前最可执行，小仓 starter 允许。
    3. PEGA — 位置重要，数字未跟上，等底部修复。
    4. GDYN — AI revenue proof 强，高弹性但服务经济学。
    5. EXLS — 补入 P0-，更偏行业数据决策 workflow。
    6. G — 补入 P0-/P1+，agentic operations 规模候选。
    7. TASK — tactical，等反转。
    8. BOX — observation+，content control-plane 候选但 bundle 风险大。
    9. BLZE — observation，AI storage proof 需转成 dollars / NRR。

    逐票深研卡片¶

    VRNS — Varonis¶

    • 当前层级：Core P0（最干净控制层）
    • 产业链位置：AI data permission / DSPM / AI-era data security guardrail
    • 不可替代性：企业数据权限图谱、非结构化数据暴露面、审计/行为基线；agent 接入企业数据前的 fail-closed 控制点。
    • 主要风险：MSFT/Purview/Defender、NOW/CRM workflow 权限、平台 bundling；SaaS ARR conversion 可能掩盖真实新增。
    • 买入纪律：等回踩或突破回踩；不是当前追高；29-32 reset/recheck；34.5-36 reclaim；<29/29.5 试仓失效；计划仓位 10%-15% trial / max 33%-50% plan。
    • 上调触发器：Atlas / AI security attach、SaaS ARR ex-conversion、新 logo/expansion 继续强。

    CVLT — Commvault¶

    • 当前层级：P0- / 当前最可执行小仓
    • 产业链位置：AI-era cyber resilience / backup / recovery / data rollback
    • 不可替代性：备份恢复一旦嵌入生产系统，切换成本高；AI/agent 让数据破坏、误操作、勒索恢复更刚性。
    • 主要风险：AI-specific revenue 未量化；RBRK/MSFT/CRWD 平台竞争；若只剩“AI 让风险更多”的叙事则降级。
    • 买入纪律：可先小仓，不把它写成 AI 原生控制层；116-121 starter；123-125 reclaim add；>125.5 no chase；<109 exit/re-underwrite；计划仓位 25%-33% plan / max 50% plan。
    • 上调触发器：SaaS ARR/FCF 维持、Satori/data security 整合产生可见 attach。

    PEGA — Pegasystems¶

    • 当前层级：P0- / workflow control-plane 候选
    • 产业链位置：BPM / decisioning / agent workflow harness
    • 不可替代性：企业 case、规则、审批、例外处理和审计链路深；agent 真落地需要 system-of-action。
    • 主要风险：Q1 revenue -10%；NOW/CRM/MSFT 收编风险最高；AI attach/RPO 证据未完全量化。
    • 买入纪律：等底部和趋势修复；不因 Blueprint AI 口号追；33.5-35 base；36.5/38 trend repair；<31.8 fail/re-underwrite；计划仓位 10%-15% trial / max 33% plan。
    • 上调触发器：Pega Cloud ACV 继续 +20%+、Blueprint AI 转成 ACV/RPO/签单和收入再加速。

    GDYN — Grid Dynamics¶

    • 当前层级：P0- / 高弹性 AI engineering
    • 产业链位置：enterprise AI implementation / production engineering
    • 不可替代性：AI revenue 占比已达 29.3%，GAIN 平台和 hyperscaler-influenced pipeline 提供生产化实施入口。
    • 主要风险：服务经济学、项目制、SI/平台竞争；AI revenue mix 若不继续提升则不能核心化。
    • 买入纪律：等回踩或趋势确认；5.8-6.1 reset；6.8-7 reclaim；<5.4 fail；计划仓位 10%-15% trial / max 33% plan。
    • 上调触发器：AI revenue mix 继续上升、GAIN 平台产品化、gross margin/FCF 不被项目交付拖垮。

    EXLS — EXLService¶

    • 当前层级：P0- / domain data-decision workflow 候选
    • 产业链位置：vertical data operations / AI decisioning / industry workflow
    • 不可替代性：保险/医疗/金融等行业数据、流程和交付嵌入；比纯 AI services 更接近垂直数据决策工作流。
    • 主要风险：AI mix 未完全量化，仍是服务/解决方案经济学；伙伴背书不能替代客户货币化。
    • 买入纪律：待完整单名确认后小仓，现价可观察不急追；27-29 starter/recheck；31-33 reclaim；36.5 no-chase；<26.5 fail；计划仓位 10%-15% trial after confirmation / max 33% plan。
    • 上调触发器：data/AI revenue 或大型垂直合同更透明、adjusted margin 维持、guidance 上修。

    G — Genpact¶

    • 当前层级：P0- / agentic operations scale candidate
    • 产业链位置：agentic operations / enterprise process AI
    • 不可替代性：流程最后一公里、domain/process know-how、Advanced Technology Solutions 已占 27% 收入。
    • 主要风险：agentic operations 仍有 management framing；平台和大 SI 压价；整体增长中速。
    • 买入纪律：待完整单名确认后小仓；更稳但弹性较低；30-32 starter；34.5-37 reclaim；40.5 no-chase；<28.5 fail；计划仓位 10%-15% trial after confirmation / max 33% plan。
    • 上调触发器：ATS 占比和增长继续提高、gross margin expansion 延续、agentic contracts 可量化。

    TASK — TaskUs¶

    • 当前层级：Tactical / INOD-like 高赔率低质量
    • 产业链位置：AI Safety / model training-maintenance / HITL ops
    • 不可替代性：AI safety、模型训练维护和 human fallback 短期真实；客户运营嵌入。
    • 主要风险：既是 AI 受益者也是自动化受害者；AI 收入绝对规模未清楚披露；BPO/CX 基础业务拖累。
    • 买入纪律：没有底部不买；只做 reversal 期权；>6.2-6.5 reclaim 才试；<5.4 fail；不做下跌摊低；计划仓位 0%-10% only after reversal / max 20% plan。
    • 上调触发器：AI Services 占比/绝对收入披露、总收入和 EBITDA 同步改善、客户集中稳定。

    BLZE — Backblaze¶

    • 当前层级：Observation / DOCN-like 存储暗线
    • 产业链位置：AI object storage / low-cost data infra
    • 不可替代性：低成本、简单、反锁定 object storage；AI 数据量增长受益。
    • 主要风险：hyperscaler/R2/Wasabi/DOCN 价格竞争；AI customer count 未等于收入/NRR。
    • 买入纪律：不追；等 reset 或 AI ARR material；6.6-6.9 reset；>8.1 no chase；AI ARR material 才上调；计划仓位 0%-15% only on reset / max 20% plan。
    • 上调触发器：B2 ARR + AI customer dollars 明确提升、毛利/FCF 改善跟上。

    BOX — Box¶

    • 当前层级：Observation+ / content control-plane 候选
    • 产业链位置：enterprise content + permissioned AI knowledge layer
    • 不可替代性：企业内容库、权限、治理、workflow；agent 需要安全读取非结构化企业知识。
    • 主要风险：MSFT 365/SharePoint/Copilot/Purview 与 Google bundle 风险极高；AI monetization 未充分量化。
    • 买入纪律：观察，不进核心；可高于普通 observation；24.2-25 reset；>28.5 reclaim；AI monetization proof before promotion；计划仓位 0%-15% only on proof/reset / max 20% plan。
    • 上调触发器：Enterprise Advanced / Box AI / agents 体现在 RPO、NRR、attach 和大客户扩张。

    从DOCN/INOD外推的机制¶

    DOCN 与 INOD 是这条线的两个 benchmark，而不是这轮 fresh-buy 核心。DOCN 证明 AI-native cloud / inference-agentic workload 能把旧 SMB cloud 框架打穿；INOD 证明 training/post-training/evals/HITL 可以从低估服务变成 AI lifecycle ops。但两者都已被发现，当前更多用于校准标准：必须有 AI ARR、AI revenue、RPO、guide、margin、FCF 或客户 engagement 这类 hard proof。

    FROG 与 FSLY 作为框架对照保留：FROG 是 model/agent artifact governance 的高质量但已高估值 benchmark；FSLY 是 edge/security/app delivery 二阶 infra 的正在被发现样本。

    触发器 / kill criteria¶

    • 没有量化 AI monetization，不进 Core P0。
    • 服务公司没有 AI mix、margin、multi-year embed 或 backlog 证据，不进 Core P0。
    • 被 MSFT/NOW/CRM/CRWD/DDOG/NET/RBRK/hyperscaler bundle 后只剩补位价值的，降到 P1/观察。
    • 只证明“AI 让需求增加”，但没有控制点或 dollars 的，最多 P1。
    • 高质量已发现 benchmark 不等于 fresh buy；DOCN/INOD/FROG 都要与未发现候选分开。
