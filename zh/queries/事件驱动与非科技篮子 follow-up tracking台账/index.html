    0. 总原则¶

    这批不是科技主线，也不是长期核心评分重算。重点是： 1. 事件是否只是临时冲击； 2. 冲击结束后，估值是否有修复空间； 3. 若冲击暴露的是需求、杠杆、资金来源、监管或执行问题，就按永久损伤处理； 4. 不把“便宜”自动写成 Buy；不把“弹性大”写成质量高。

    核心分层： - 纯事件错杀：NCLH > ALK > LUV > TNL。 - 质量 / 高利率韧性 overlay：BKNG + V/MA，可加 ABNB / EXPE 观察。 - 航运、化工、物流：多数不是和平受益篮子，只能另开扰动交易。 - 金融、fintech、healthcare：按已有评分卡跟踪宏观错位，不重写结论。

    1. 事件触发器¶

    触发器 影响方向 主要跟踪篮子 处理口径
    美伊战争降温 / 停火 / 航线风险下降 fuel、旅行情绪、信用利差修复 cruise / airlines / travel 只对 NCLH / ALK / LUV / TNL 算一阶事件触发。
    原油 / 航空燃油冲击回落 成本压力下降 airlines / cruise / travel leisure 若油价回落但股价不修复，要怀疑需求或公司问题。
    旅行信心恢复、cross-border 恢复 需求与支付量修复 OTA、payments、travel platform BKNG / V / MA 是质量 overlay，不是深度错杀。
    高利率 / sticky inflation 延续 债务、再融资、消费信贷承压 cruise、airlines、fintech、banks、alts 杠杆高或资金来源脆弱者降权。
    信用或资金供给收紧 funding、credit loss、multiple reset fintech、banks、alts、cruise 优先看资金来源稳定性、坏账、covenant、资本要求。
    政策 / 监管 / 医保支付变化 估值中枢重定价 healthcare、fintech、payments、banks 监管若改写商业模式，按永久损伤。

    2. 临时冲击 vs 永久损伤判别¶

    临时冲击： - 事件路径清楚：战争、油价、航线、旅行情绪、信用利差。 - 公司自身证据没有显示需求塌陷、成本结构失控、融资困难或监管重写模式。 - 估值已经压到能解释为 sentiment overkill。 - 事件缓和后，价格、订单、booking、cross-border、资金条件至少应有方向性修复。

    永久损伤： - 油价回落 / 战争缓和后仍不反弹。 - issuer-primary evidence 显示需求、成本、leverage、covenant、整合、劳工、监管或 pipeline 问题不是临时事件。 - 低估值来自盈利下修、信用恶化、资本要求提高或商业模式折价。 - 需要再融资却遇到高利率 / credit spread 压力。

    3. 主台账：travel / airlines / cruise / OTA¶

    名字 当前角色 事件触发 临时冲击假设 永久损伤信号 资产负债表重点 估值重置观察 退出纪律
    NCLH cruise / travel 高弹性；当前 best fit / overkill first 战争结束、油价回落、旅行信心修复、credit spread 修复 10-K 暴露 fuel、消费信心、航空接驳、信用市场；股价自 baseline 约 -35.2%，FPE 约 7.7x，可解释为情绪杀过头 若需求本身坏掉，或杠杆 / covenant 变成主风险，就不是临时错杀 杠杆和 covenant 是第一检查项；后续必须补 earnings / guidance / balance-sheet check 低 FPE 只在需求未坏时有效；若估值低来自盈利下修，不能上调 油价回落但不反弹；或公司证据显示需求 / 成本 / leverage 自身恶化，退出事件篮子
    ALK 中盘航空；best airline fit fuel shock 退潮、旅行情绪修复 航空燃油和高固定成本传导最直接；股价约 -26.0%，FPE 约 6.0x Hawaiian integration、labor、Boeing / fleet 问题不是战争结束能解决 检查整合成本、劳工成本、fleet / Boeing 约束、流动性 FPE 低但需确认 earnings 不继续下修 若油价回落仍不修复，或整合 / fleet 成为主叙事，降为普通航空风险
    LUV 较高质量航空反弹；less hidden fuel 回落、旅行恢复 fuel 是第二大成本，2025 已终止剩余 fuel hedge portfolio；股价约 -20.2%，FPE 约 8.7x turnaround、activist、成本结构是独立变量 wiki 口径里 LUV 资产负债表较好，但仍需复核 cash / debt / labor 更像质量 rebound，不是 hidden deep value 若成本结构或 turnaround 失败主导，退出事件错杀叙事
    TNL travel / leisure 二阶 beta airfare、air-carrier capacity、consumer confidence 改善 旅行需求受 fuel shock 和消费者信心影响；股价约 -14.9%，FPE 约 7.4x 链条二阶，若消费需求本身走弱，事件修复不足 复核消费信贷、预订、现金流和 debt maturity 便宜但弹性弱于 airline/cruise 若旅行情绪修复但需求无改善，移出核心篮子
    BKNG OTA / travel toll road；质量 compromise 旅行恢复、cross-border 改善 asset-light，baseline 约 -7.8%、1M 约 -11.8%；不直接承担 fuel / labor / cruise debt 不是深度 war casualty；若估值仍高且回撤不够，赔率一般 资产轻；重点不是 debt，而是现金流质量与平台需求 质量回撤，不按便宜小票处理 若没有进一步回撤或估值重置，不追高；只做质量 hedge
    ABNB asset-light travel platform beta travel confidence 修复 cash 多于 debt，低资产重，少受 fuel / refinancing 冲击 regulation、valuation、consumer discretionary 仍是硬约束 关注现金多于 debt 是否维持、监管成本 估值要单独复核；不能因低资产重自动 Buy 监管或估值风险压过旅行 beta 时退出
    EXPE cheap-ish OTA；质量低于 BKNG 平台旅行需求修复 FPE 约 9.5x，平台敞口，少承担 fuel / cruise debt 执行质量不如 BKNG；baseline 后没有 clean war drawdown 看执行、margin、现金流，而非 fuel 便宜但不构成战争错杀 若只是便宜、没有 drawdown 和执行改善，不升级
    V / MA payments / macro-quality hedge cross-border travel、名义支付量修复 高 margin，收入与支付量相关，比 airline/cruise 更能承受 inflation 不是战争错杀，估值是 premium compounder 资产负债表不是核心；监管 / fee / volume 是核心 不能按低估值处理；看 premium 是否合理 若估值过贵或监管/费率争议重估，降权；不写成战争低估票

    执行结论： - 只想要最大事件弹性：优先 NCLH，航空表达选 ALK，质量反弹选 LUV。 - 想对冲半导体过热和高利率风险：优先 BKNG + V/MA，不要简单加大 NCLH / ALK。 - DAL / UAL / AAL / CCL / JBLU / SNCY / ALGT 只作 benchmark 或二线观察，除非刷新 size、估值、流动性和 earnings 后再单独立项。

    4. 航运 / 化工 / 物流：当前为 reject 或另开交易¶

    组别 名字 事件触发 为什么不进核心 跟踪指标 退出纪律
    tanker / shipping INSW Middle East / Israel / Iran / US hostilities、crude / products trade、tanker demand 地缘扰动可能提高 tanker demand；normalization 可能让 tanker rates decline，和平不一定利好 tanker rates、route disruption、war-risk、trade flow 不把它写成战争结束受益；只有另开“扰动受益”交易才复核
    shipping LPG / GNK / ZIM Strait / Red Sea / bunker / war-risk 有战争暴露，但方向不是纯 peace beneficiary bunker cost、route、freight rates、war-risk premium 若和平导致 rates 下行，不能当错杀修复
    chemicals WLK energy / feedstock / demand 下跌明显但 valuation 不便宜，更像 demand / earnings 问题 feedstock、volume、earnings revision、EV/EBITDA 没有估值与需求改善前不升级
    chemicals ASH energy / feedstock 只是轻微下跌，战争链条弱 input cost、margin、需求 缺少直接性和 drawdown，不进核心
    chemicals OLN / CC energy、制裁、战争或 refinancing 有暴露但股价没有被这条线杀下来 refinancing、energy cost、earnings 无事件错杀证据则不升级
    logistics CHRW / XPO fuel、freight cycle 估值不够便宜；fuel pass-through、freight cycle、execution 更重要 freight cycle、fuel pass-through、execution 除非估值重置且执行改善，否则继续 reject

    9. 估值重置纪律¶

    1. 先问低估值来源：是情绪错杀，还是盈利质量下修。
    2. travel 事件篮子只接受“低倍数 + 事件暴露 + 事件结束受益 + 非永久损伤”。
    3. BKNG / V / MA 是质量 overlay，不用低估值逻辑强行解释。
    4. fintech 的低倍数必须配合 funding 和信用质量；否则是价值陷阱。
    5. healthcare 的低估值必须配合 pipeline、政策、赔付率或增长证明。
    6. finance 的便宜必须扣除监管、资本、信用和退出周期。

    10. Exit discipline¶

    立即退出 / 降级触发： - 原油回落、战争降温，但核心 travel 名字不反弹。 - 新 earnings / guidance 显示需求、成本、杠杆、covenant、整合问题独立恶化。 - 高利率继续压制 refinancing，且公司现金流不足以缓冲。 - fintech 出现 funding 收紧、信用损失恶化、合作方集中度扩大。 - healthcare 出现政策、赔付率、管线、商业化证据恶化。 - finance 出现资本要求、信用事件、监管、地缘变量重估。 - 价格先修复到估值不再便宜，但基本面未同步证明。

    不升级触发： - 只有股价反弹，没有 earnings / guidance / balance-sheet 支持。 - 只是“看起来便宜”，但没有明确催化或永久损伤排除。 - shipping / tanker 因战争扰动受益，却被误放进“和平受益”篮子。

    11. 下一代理 checklist¶

    必须做： - [ ] 刷新 market snapshot：NCLH / ALK / LUV / TNL / BKNG / ABNB / EXPE / V / MA。 - [ ] 对 NCLH / ALK / LUV / TNL 补 earnings / guidance / balance-sheet check。 - [ ] 对 NCLH 单独检查 debt、covenant、credit spread / refinancing 敏感度。 - [ ] 对 ALK 单独检查 Hawaiian integration、labor、Boeing / fleet。 - [ ] 对 LUV 单独检查 fuel hedge 终止后成本暴露、turnaround、activist 变量。 - [ ] 对 TNL 检查 airfare、air-carrier capacity、consumer confidence 对需求的传导。 - [ ] 对 BKNG / ABNB / EXPE 分开复核 asset-light、估值、执行质量；不要混成同一质量层。 - [ ] 对 V / MA 复核 cross-border、premium valuation、regulatory / fee 风险。 - [ ] 航运只按“扰动交易”复核，不要自动写成和平受益。 - [ ] 化工 / 物流若要重开，必须同时满足 drawdown、估值、直接性、和平受益四个门槛。 - [ ] Fintech 复核 funding、credit quality、资金来源集中度，再决定是否改动作。 - [ ] Healthcare 复核 policy、pipeline、utilization / loss ratio、commercial proof。 - [ ] Finance 复核 capital requirement、credit、fundraising / exits、capital markets activity。

    禁止做： - [ ] 不把本草稿直接回写 active wiki。 - [ ] 不创建新 entity 页。 - [ ] 不给 TradingView marking zone。 - [ ] 不把 NCLH / ALK 写成高质量 hedge。 - [ ] 不把 BKNG / V / MA 写成战争错杀低估票。 - [ ] 不把 shipping 因扰动受益误读为和平受益。

    可升级条件： - [ ] 事件冲击明确缓和； - [ ] 核心名字价格仍未完全修复； - [ ] 最新 earnings / guidance 没有显示永久损伤； - [ ] balance sheet 能承受高利率 / refinancing； - [ ] 估值仍给足安全边际； - [ ] 退出纪律可量化。

    12. 当前结论¶

    最适合 Batch 6 后续跟踪的不是宽泛非科技篮子，而是三层： 1. 事件弹性小仓：NCLH / ALK / LUV / TNL。 2. 质量分散层：BKNG + V/MA，必要时看 ABNB / EXPE。 3. 宏观风险仪表盘：fintech、healthcare、finance 维持原评分卡动作，只追踪 funding、credit、policy、capital markets 这些能重写估值的变量。

    真正的无效信号只有一个：事件缓和后仍不修复，且公司证据说明问题不是战争 / 油价 / 情绪，而是自身基本面。
