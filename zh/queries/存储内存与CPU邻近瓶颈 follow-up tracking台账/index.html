    0. 总结先行¶

    本批跟踪桶不是“再找一个最热 AI 票”，而是把 AI infrastructure 的二级/一级瓶颈拆成四条可监控链：

    1. Memory / HBM pricing：硬瓶颈最强。MU 是 anchor；RMBS 是 memory-interface/IP 暗线。
    2. Datacenter flash / storage：近端财报动能最硬，但更像二级放大瓶颈。SNDK、WDC 已被重估，纪律是 no-chase / pullback-only。
    3. Interface / IP / memory movement：RMBS 逻辑真，但估值已 premium；看 product revenue、HBM4E/CXL、design-win，而不是只听叙事。
    4. CPU-adjacent bottleneck：CPU 需求真实，但不等同 HBM。AMD/INTC/ARM/QCOM 要按“host compute、agentic workflow、custom silicon、edge/terminal AI”分层验证。

    核心纪律： - HBM / memory bandwidth 是一级硬约束； - storage I/O、CPU、system memory、RAG/ETL/data pipeline 是二级放大瓶颈； - 动能高不等于现在可追； - TradingView 只做边界继承与待刷新清单，不做任何自动 watchlist / alert / chart mutation。

    2026-07-07 Samsung guidance note：Samsung 官方 Q2 2026 guidance（sales KRW 171T、op profit KRW 89.4T、OPM 52.3%）把 memory/pricing upcycle 的 sector proof 推硬；但它不拆 segment/HBM/foundry，也没有客户认证或实际出货信息，所以只提升“需要继续跟踪 memory / HBM pricing”的优先级，不改变 MU/SNDK/WDC/RMBS 的 action discipline。

    动作纪律： - 只把 Samsung guidance 用作 memory-cycle confirmation。 - 不把 headline profit spike 直接转译成 Samsung / MU / SNDK / WDC 的 fresh buy 或 TV/HERMES line change。

    当前 wiki 证据： - FQ2 FY2026 revenue USD 23.86B；non-GAAP gross margin 74.9%；non-GAAP EPS USD 12.20。 - FQ3 guide：revenue USD 33.5B，gross margin 约 81%，non-GAAP EPS USD 19.15。 - 管理层口径：demand strong、industry supply tight、memory has become a strategic asset。

    后续跟踪指标： - DRAM/HBM pricing 是否继续上行，还是开始正常化； - HBM allocation 是否仍紧，客户是否继续提前锁供； - gross margin 是否维持异常高位，还是开始快速均值回归； - capex 增加是否开始提前透支下一轮供给； - HBM share / node / packaging 兑现是否继续支持 premium multiple。

    升级触发： - 后续 guide 继续上修，且 gross margin 没有明显回落； - HBM 供给紧张从单季强扩展到多季可见； - 客户消化没有恶化，pricing 与 volume 同时成立。

    降级触发： - HBM/DRAM pricing 开始正常化，或客户库存/消化压力出现； - gross margin 从异常高位明显回落； - capex 周期重启导致市场开始交易供给过剩； - 股价继续扩 multiple，但证据只是在重复旧强周期。

    动作纪律： - MU 是 premium anchor / benchmark，不是 hidden treasure。 - 只在 thesis 未破且价格回到已定义回撤区时考虑加；高位只做观察。

    4. Datacenter flash / storage 跟踪¶

    SNDK：datacenter flash / NBM contracting story¶

    当前 wiki 证据： - Q3 FY2026 revenue USD 5.95B。 - Datacenter revenue USD 1.467B，+233% QoQ / +645% YoY。 - Q4 guide USD 7.75B-8.25B。 - 公司称 Q3 是 fundamental inflection，并披露多年 NBM customer commitments。

    后续跟踪指标： - NBM 多年承诺的真实毛利质量； - financial guarantees、客户集中、合同价格机制； - datacenter flash 是否继续高增，还是一次性抢供； - NAND pricing 是否因供给/周期而反噬； - 暴力 rerating 后估值是否已把新范式打满。

    升级触发： - 下一季继续证明 datacenter revenue 与 gross margin 同步强； - NBM 合同质量清楚，且不是牺牲未来价格弹性换来的 headline； - 客户集中风险下降，或更多客户/应用进入 revenue。

    降级触发： - NAND pricing 正常化； - 客户承诺降温或合同条款质量低于预期； - datacenter 增速回落但股价仍按 vertical rerating 定价； - gross margin 回落、库存或客户消化压力上升。

    动作纪律： - 当前是 deep-dive / no fresh chase。 - 买点只能来自回撤后复核，而不是追 post-earnings vertical move。

    WDC：nearline / AI storage infrastructure¶

    当前 wiki 证据： - Q3 FY2026 revenue USD 3.34B，+45% YoY。 - non-GAAP gross margin 50.5%。 - free cash flow USD 978M。 - 管理层将 training / inference / agentic AI / physical AI 产生的持久化数据需求写入核心口径。

    后续跟踪指标： - nearline pricing 是否持续； - hyperscale qualification / demand digestion； - high-capacity roadmap 是否继续转成 revenue； - gross margin >50% 的可持续性； - FCF 是否跟随高毛利持续，而非一次性释放。

    升级触发： - Q4 / 后续季继续验证高毛利和云端需求； - 100TB+ roadmap、High Bandwidth Drive、hyperscale qualification 有更清晰转化； - FCF 持续强，且不是短期 working capital 波动。

    降级触发： - hyperscaler digestion 放缓； - HDD/nearline pricing 回落； - gross margin 不能维持，或 FCF 明显回落； - 股价继续按 AI storage 高景气外推，但新 proof 不足。

    动作纪律： - watch / pullback-only。 - WDC 是 storage infrastructure serious watch，不是 HBM 级硬瓶颈。

    DELL / ORCL / SANM / FLNC：只作 read-through，不混桶¶

    • DELL：AI server、storage、networking 与 enterprise AI factory 交付层真实；本批只跟 storage attach、AI server backlog 转收入、ISG margin 与 cash conversion。
    • ORCL：RPO USD 553B、IaaS +84%、FY2026 capex USD 50B 是全链需求锚；本批只用它验证 storage / network / power 外溢是否持续。
    • SANM：ZT 后 cloud & AI infrastructure manufacturing 证据增强，产品例子含 storage；但不能把它写成已证明 storage pure play。
    • FLNC：属于园区/电网侧储能与 backup，不是 datacenter data storage；本批只提醒术语边界，不纳入 flash/HDD ledger。

    5. Interface / IP 跟踪¶

    RMBS：memory movement / HBM4E / CXL 暗线¶

    当前 wiki 证据： - Q2 2026 revenue USD 207.4M，above prior guidance；product revenue USD 99.2M，QoQ +13%、YoY +22%。 - Q2 licensing billings USD 84.1M，operating cash flow USD 61.2M，cash / marketable securities USD 824.9M。 - Q3 guide：revenue USD 210M-216M，product revenue USD 110M-116M，royalties USD 69M-75M，non-GAAP EPS $0.75-$0.82。 - 公司口径覆盖 DDR5 9600 server/client memory module chipsets and PCIe 7 Switch IP for next-generation AI systems；HBM4E/CXL/design-win monetization still needs proof。 - 2026-07-27 snapshot USD 96.50 sits below 20d/50d/100d/200d averages while issuer proof improved; this creates a local starter/recheck setup, not a fully closed buy signal.

    后续跟踪指标： - product revenue 是否按 Q2 guide 回升； - HBM4E controller IP / CXL 从 option 走向 design-win / monetization； - licensing billings 与 cash flow 是否稳定； - memory-interface 芯片收入是否受 DDR5 / server refresh 支撑； - 市场是否把前瞻 IP 过度资本化。

    升级触发： - product revenue 连续上修或超 guide； - HBM4E/CXL 有更清楚客户、design-win、收入节奏； - 估值不再扩张但基本面继续增强。

    降级触发： - product revenue 继续弱于预期； - HBM4E/CXL 仍停留在路线图与 PR； - licensing/royalty 不能支撑 premium； - 股价继续高位，但 monetization proof 没跟上。

    动作纪律： - RMBS 是 memory-interface hidden-ish 候选，Q2 product-revenue proof improved but is still positive partial. - Local candidate zones after Q2: USD 80-88 deep reset/add，USD 90-100 small starter，USD 108-116 reclaim/retest，USD 128-140 no-chase，USD 150-170 trim/avoid new money. - 不可用“HBM 很缺”直接推导成追价；Q3 customer agreements、call/Q&A 和 HBM4E/CXL design-win conversion 是下一 gate。

    6. CPU-adjacent bottleneck tests¶

    6.1 基础判断¶

    CPU 瓶颈真实，但不是 HBM 级一级硬短缺。

    AI 数据中心路径： power -> accelerator package -> HBM -> interconnect -> server/rack -> CPU+DRAM host -> storage/network -> scheduler/software -> paid workload

    分层： - 一级硬瓶颈：accelerator compute、HBM capacity/bandwidth、advanced packaging、power/cooling/network fabric。 - 二级放大瓶颈：CPU、system memory、storage I/O、RAG/ETL/data pipeline、orchestration/control plane。 - agentic 特有瓶颈：工具调用、检索、浏览、代码执行、数据库访问、沙箱/容器调度、安全检查、多 agent 并发。

    测试原则： - 看 CPU 是否让 GPU/accelerator utilization 下滑； - 看 agentic workflow 是否带来可计量 CPU/DRAM/server attach； - 看瓶颈能否被更多 host、DPUs/IPUs、cache、异步 pipeline、软件优化吸收； - 不能把单一公司供给约束等同全行业 CPU 硬短缺。

    6.2 AMD：平台二号位，而非 CPU pure bottleneck¶

    当前 wiki 证据： - Q1 FY2026 Data Center revenue USD 5.775B，同比 +57%。 - 管理层称 inferencing 和 agentic AI 推高 high-performance CPUs and accelerators 需求。

    后续测试： - Data Center 中 CPU vs accelerator 的增长拆分； - EPYC ASP / volume； - Instinct、Helios、ZT/Sanmina 后 AI infrastructure platform pipeline； - ROCm / ecosystem / customer visibility 是否继续改善。

    升级触发： - CPU 与 accelerator 同时强，且客户/生态可见度提高； - 服务器 CPU 需求改善不是一次性补库； - AI infrastructure platform 能提高 margin / revenue durability。

    降级触发： - accelerator backlog 透明度不足，或生态差距扩大； - CPU 强但被估值完全 price in； - Data Center 增速放缓，或 margin 环比不改善。

    动作纪律： - AMD 是 AI infrastructure platform hold / no-chase。 - 不把它当 CPU bottleneck pure play。

    6.3 INTC：需求改善不等于跳过执行风险¶

    当前 wiki 证据： - Q1 FY2026 DCAI revenue USD 5.1B，同比 +22%。 - server ASP +27%、volume -5%。 - 公司披露 market demand exceeded available product supply due to internal supply constraints。

    后续测试： - DCAI volume 是否从 -5% 转正； - internal supply constraints 缓解后 ASP 是否仍维持； - CPU 产品竞争力是否改善，而非单纯供给少导致价格好； - Intel Foundry 是否拿到外部客户，不只是内部成本中心； - capex / FCF 压力是否可控。

    升级触发： - DCAI volume 转正且 ASP 不崩； - foundry 外部客户与先进封装/制造路线形成实证； - FCF / capex 压力边际改善。

    降级触发： - 供给约束解除后 ASP 快速回落； - foundry 继续消耗资本但无外部客户 proof； - 产品竞争、制造、资本开支三重风险没有改善。

    动作纪律： - 当前 Sell / avoid / no new position。 - 不能因为“CPU 也重要”就忽略执行风险与估值。

    6.4 ARM：IP 底座真实，但 AI server CPU 钱包不自动流向 Arm¶

    当前 wiki 证据： - Arm 在云、AI、HPC、自研服务器芯片里有 Neoverse / CSS / IP 底座位置。 - AMD 强 EPYC print 提醒：AI 服务器 CPU 增量仍能明显流向 x86。

    后续测试： - hyperscaler 自研 server CPU 是否扩大实际 deployment，而非只停留在 IP narrative； - Neoverse / CSS 是否带来更高 royalty / license 可见度； - x86 在 AI server host CPU 中是否真正丢 share； - 估值是否为兑现留出足够缓冲。

    升级触发： - cloud/custom CPU deployment 与 royalty economics 更清楚； - ARM server penetration 有多客户、多季度 proof； - 估值回落到能容纳兑现不确定性。

    降级触发： - AI capex 继续增长但 x86 仍吃主要服务器 CPU 增量； - 授权/诉讼/客户自研边界扰动； - 估值继续高位但 revenue proof 不足。

    动作纪律： - 当前 Sell。 - IP 地位不等于当前好买点。

    6.5 QCOM：edge/custom silicon 条件票¶

    当前 wiki 证据： - Q2 FY2026 revenue USD 10.599B，同比小幅下滑。 - QCT handset -13% YoY，Automotive +38%，IoT +9%。 - 管理层提到 leading hyperscaler custom silicon engagement 年内初始出货。

    后续测试： - hyperscaler custom silicon 初始出货是否有 economics； - data-center custom silicon 是否能改变 QCOM purity； - handset/QCT 周期是否拖累估值； - edge AI / AI PC 是否从故事进入规模。

    升级触发： - custom silicon 出货有客户、规模、毛利或 roadmap proof； - handset 不再压制整体； - valuation 仍低于增长质量。

    降级触发： - custom silicon 只停留在单点 engagement； - handset/QCT 继续下滑； - edge AI 不能转化为收入； - 股价提前交易 AVGO-style ASIC proxy，但证据不够。

    动作纪律： - Watch / pullback-buy only。 - 不能把 QCOM 直接写成数据中心 ASIC 纯代理。
