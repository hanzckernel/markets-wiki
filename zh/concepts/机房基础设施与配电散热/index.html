    行业级背景¶

    • Tom’s Hardware：高密度 AI 机柜让传统风冷在 20–30kW 以上明显吃力，液冷正快速上升。
      来源：https://www.tomshardware.com/pc-components/cooling/the-data-center-cooling-state-of-play-2025-liquid-cooling-is-on-the-rise-thermal-density-demands-skyrocket-in-ai-data-centers-and-tsmc-leads-with-direct-to-silicon-solutions
    • IEA：冷却在不同类型数据中心中的电耗占比差异很大，高效 hyperscale 与低效企业机房差别明显。
      来源：https://www.iea.org/reports/energy-and-ai/energy-demand-from-ai

    这层当前最重要的增量认识¶

    这层现在不该只被理解成“卖机房设备”。更接近的表述是： - 机房前端的配电、开关柜、变压器、液冷、楼宇系统与 MEP 交付，正在一起决定 time-to-power； - 因此这里面既有产品公司，也有工程交付公司； - 很多公司并不便宜，但它们解决的是真正让 AI 园区落地的约束。

    2026-06-05 NVTS / NVIDIA 800 VDC 复核后，这层的重要性反而更清楚：800V 架构不是只发生在板上，它会把更多复杂度推到 power room、switchgear、rack-entry power shelves、transformers、bus / protection 与冷却协同。这里要区分 direct 800V named ecosystem 与 facility-side commercial proof：NVTS 的 named architecture proof 更直接，但 POWL 的 data-center order dollars 更硬；HPS.A 是 slower-burn transformer / power-quality read-through；VRT / ETN 是 named ecosystem read-through，HUBB / NVT 暂只写 broad facility read-through。

    快速判断¶

    • GEV GE Vernova — 平台 / 偏直接；Q1 2026 Power + Electrification 已把燃机 backlog、grid equipment 与 data-center equipment orders 打到订单和 backlog 层。；一句话判断：【电力/电网平台】不是纯机房设备商，也不是电力资产 owner；当前 premium/no-chase，主 reset-underwrite 看 USD760-830。
    • HUBB Hubbell — 条件 / 偏直接；Q1 2026 同时验证 Grid Infrastructure、data-center electrical demand 与 765kV high-voltage transmission。；一句话判断：【电网 / 电气交付】值得进 deep-dive bucket，但当前约 USD516 已是 quality premium，不是明显低估，先等 USD430-470 或等 EPS 上修证据。
    • ETN Eaton — 直接 / 平台锚；Fibrebond modular power enclosures 与 Boyd Thermal liquid cooling 把 data-center 电气/热管理覆盖拉宽。；一句话判断：【电气平台】强 relevance，但估值已是 premium electrical compounder，更像 comparison anchor / pullback reserve。
    • VRT Vertiv — 直接；收入与订单结构都说明它不是故事股，而是真需求锚。；一句话判断：【机房总成】业务最硬，但价格通常也最先反映预期。
    • POWL Powell Industries — 条件 / 偏直接；Q1 后数据中心订单已真实出现，Q2 后又披露 value exceeding USD 400M 的 mega data-center order，商业 proof 比 NVTS 当前收入归因更硬，但 rerating 也已经发生。；一句话判断：【配电】time-to-power 受益真实，仍是第一入口，但更适合写成 pullback-only。
    • HPS.A Hammond Power Solutions（内部维护页，未公开） — 条件；Q1 2026 继续把 record sales 与 data centre-related activity / backlog 增长联系起来，说明受益不是空泛映射。；一句话判断：【变压器 / 配电件】受益真实，但更偏慢变量设备供应，仍缺 named customer 与量化DC拆分。
    • JCI Johnson Controls — 条件 / 偏直接；冷却与 building systems 的订单与 backlog 已越来越受数据中心项目驱动。；一句话判断：【楼宇 / 冷却】广义平台，不是纯 AI 票，但在 buildout 里位置更真了。
    • NVT nVent — 条件；liquid cooling 与 rack power 组合逻辑成立，但 monetization 证据仍弱于一线锚点。；一句话判断：【电气 / 冷却】方向对，仍需更多订单与收入证明。
    • PWR Quanta Services — 直接 / EPC 交付；Q1 2026 issuer-primary evidence 直接把 utility demand 与 data centers、technology dynamics、reshoring 和 electrification 联系起来。；一句话判断：【电网/EPC】time-to-power 执行瓶颈真实，但 contractor economics 与高估值决定当前 no-chase。
    • EME EMCOR Group — 条件；mission-critical MEP 与施工能力真实，但 contractor economics 决定它不应被当成纯设备型 alpha。；一句话判断：【工程交付】time-to-power 约束层的重要名字，更像 broad but real beneficiary。
    • ASTK Asetek — 边缘；如果只看技术逻辑，液冷方向没问题。；一句话判断：【冷却】方向对，但体量与兑现仍早。

    当前仍未完全展开的缺口¶

    • 更广的 EPC / power engineering 链：PWR 已补成独立实体，因为 issuer-primary 证据足以支撑它作为 time-to-power 工程交付瓶颈；更长 contractor 名单仍先停在概念层，不批量引入。
    • 欧洲电气 / cooling 二线：作为区域来源与供应格局可以保留，但不把 geography 本身做成 durable bucket。
    • broad MEP / cooling beneficiaries：EME — EMCOR Group、JCI — Johnson Controls、NVT — nVent 仍值得跟，但在当前更窄的“二阶交付瓶颈”框架里，alpha 集中度通常不如 POWL。
