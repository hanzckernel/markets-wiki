    数据中心上下游首页¶

    更新时间：2026-06-04 CEST 状态：统一 Equity wiki 下的数据中心链条 / buildout lens 主页；本页只做导航与候选提示，current action 以各 entity/query/source-backed 页面为准。

    这套 wiki 在讲什么¶

    这条 lens 关注的是“AI / 云数据中心扩张，到底沿着哪些产业环节传导”。 它在统一研究体系里承担链条研究入口，不是“谁今天涨得猛”的备忘录，而是一个偏苛刻的产业链筛选 lens： - 先问链条位置是不是真的； - 再问兑现距离是近还是远； - 最后才问价格弹性值不值得追。

    当前更值得补的二阶暗线（导航提示；非 current action source）¶

    • rack / system integration：当前更适合落在 制造、封装与系统集成，重点看 DELL — Dell Technologies、CLS — Celestica、FN — Fabrinet 这类“旧制造标签”是否低估了 AI factory 交付能力；AMD FY2026 Q1 说明这层需求底色仍在变厚。
    • DCI / scale-across optics：当前更适合落在 互连、光器件与电源器件，重点看 COHR — Coherent、LITE — Lumentum、MTSI — MACOM 这组是否不应再只按传统光通信周期股理解；AMD 对 inferencing / agentic AI / large-scale deployments 的描述，让这组的 duration 更像长期而不是单轮交易。
    • advanced packaging / test / metrology：当前更适合落在 制造、封装与系统集成 与 半导体与基础算力 的交叉带，重点看 ONTO — Onto Innovation、CAMT — Camtek、TER — Teradyne、RMBS — Rambus、ENTG — Entegris；AMD 强 print 对它们更多是长期复杂度 read-through，而不是直接动作升级。
    • time-to-power engineering：当前更适合落在 机房基础设施与配电散热，重点看 GEV — GE Vernova、HUBB — Hubbell、ETN — Eaton、PWR — Quanta Services、POWL — Powell Industries、HPS（内部维护页，未公开）、EME — EMCOR Group、JCI — Johnson Controls、NVT — nVent；GEV/HUBB/ETN/NVT/PWR 已单独对照或建页，避免把电力平台、设备平台、rack/cooling 与 EPC 交付混成一种生意。
    • substrate / materials / purity：这是当前 ontology 仍相对薄的一段，phase 1 先在概念层承认它的重要性，不做大批量新实体扩张。

    为什么这条链值得单独建 wiki¶

    • IEA 估计 2024 年全球数据中心用电约 415 TWh，到 2030 年基准情形接近 945 TWh；美国和中国贡献近 80% 的增长。
      来源：https://www.iea.org/reports/energy-and-ai/energy-demand-from-ai
    • DOE / LBNL 估计美国数据中心用电在 2023 年约 176 TWh，到 2028 年可能升至 325–580 TWh，占美国总用电比重从约 4.4% 升到 6.7%–12%。
      来源：https://www.energy.gov/articles/doe-releases-new-report-evaluating-increase-electricity-demand-data-centers
