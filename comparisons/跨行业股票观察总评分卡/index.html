    这张总表怎么读¶

    • 这是跨行业导航表，不是把银行、平台、半导体和制药用单一倍数硬排的“绝对真理榜”。
    • 真正的 Buy / Hold / Sell 先在各自行业页里成立，再拿到这里做跨主题优先级排序。
    • 医药簇已经扩到 11 个名字；Phase 5 又纳入 ADBE 与中国平台六家公司，因此总表从 41 家扩到 48 家。Phase 6 只同步金融科技/医药的 raw-backed 单行漂移，不做全面重排。
    • 同分时先沿用各自主题页已经成立的排序，再按主题顺序放进总表；这里强调的是导航优先级，不是假装能用一个统一公式压平所有行业。
    • 日内涨跌只提供弱情绪输入，不足以单独改变动作。
    • 2026-04-30、2026-05-05、2026-05-14、2026-05-24 与 2026-05-29 的 earnings/current-price / AI-DC / platform evidence overlay 只做漂移校正，不重算整张 2026-04-20 总分表；最新明确变化包括 AVGO 从 Buy 降为 Hold / staged pullback-buy only 且 Q2 provisional lines 已重置为 420 / 450 / 480 / 525、AMD thesis 加强但 action 仍维持 Hold、SNDK 从旧 NAND-only 框架上修为 Hold/no-chase、ADBE 和中国平台进入平台/全局图表。

    四象限总览¶

    • 小点 = 单家公司；带标签气泡 = 板块中心。
    • X 轴 = 优势强度 = (quality_moat + growth_driver) / 2
    • Y 轴 = 代价可控度 = (valuation_setup + risk_control) / 2
    • 越靠右上，代表“优点更强、代价更可控”；越靠左下，代表当前 setup 更弱。
    • 注：全市场图里的 valuation_setup 仍然是各自行业篮子内的相对分，不是跨行业统一倍数比较。
    • 真正的逐家公司可读比较请以下面的分主题图和分主题表格为准。
