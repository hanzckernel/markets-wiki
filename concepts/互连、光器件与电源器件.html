行业级背景

  • SemiEngineering：AI 数据中心高带宽互连正快速走向全面光化。 来源：https://semiengineering.com/all-ai-data-center-interconnects-will-be-optical-within-5-years/
  • IEA：accelerated servers 是未来几年数据中心用电增长的核心驱动。 来源：https://www.iea.org/reports/energy-and-ai/energy-demand-from-ai

这层当前最重要的增量认识

当前不该只把这层理解成“800G / 1.6T 模块景气”。 如果 agentic AI 继续推高多 agent 并行、RAG / memory traffic、跨 cluster 协同与跨 region 调度，那么更值得盯的是：

  • scale-up 之外的 scale-out / scale-across；
  • DCI、coherent optics、OCS、CPO / NPO 等后续演进；
  • 谁真正控制高复杂度器件、光源、模拟器件与制造良率。

AMD Q1 FY2026 把 inferencing、agentic AI、server growth acceleration 和 large-scale deployments 写得更明确；FN 最新 Q3 FY2026 也证明 datacom program 已经在 record revenue 里兑现。CSCO Q3 FY2026 又把 networking orders >50%、data-center switching orders >40%、FY26 hyperscaler AI infrastructure orders outlook USD 5B -> USD 9B 写成 issuer-primary demand-anchor。三者合在一起，更支持把这层看成持续扩张的网络 / 光互连复杂度链，而不是一次性的训练集群交易；但 CSCO 只能写成 TAM-upside proxy，不能单独当作无条件行业 TAM 扩大证明。

2026-05-24 NVIDIA primary read-through 把 AI networking / optics 从“行业 read-through”推成更硬的一手证据：NVIDIA Q1 FY2027 Data Center revenue USD 75.2B，旧口径 Data Center networking revenue USD 14.8B、同比 +199%、环比 +35%，并披露 total supply-related commitments USD 119.0B。更关键的是四条 named evidence：MRVL 通过 NVLink Fusion 和 silicon photonics 合作接入 NVIDIA ecosystem；COHR 与 LITE 分别获得 NVIDIA multiyear agreement、multibillion purchase commitment / capacity rights 和 USD 2B investment；GLW 获 NVIDIA long-term optical-connectivity partnership，U.S. optical connectivity capacity 10x、fiber production capacity >50%。这些提升 MRVL/COHR/LITE/GLW 的证据强度，但不把 FN/MTSI/AAOI/CRDO/SMTC/MXL/ADTN/SANM 等未命名公司写成 NVIDIA 订单归因。

类型拆分规则

同属 AI networking / interconnect broad bucket，不等于就是同一种公司。

  • ANET / NOK 更接近 networking / fabric platforms：卖的是网络平台、交换/路由/光网络系统能力。
  • CRDO / ALAB / SMTC / MXL 更接近 AI connectivity semis / fabric enablers：卖的是互连芯片、fabric switch、AEC/retimer/DSP、PCIe/CXL/UALink、optical/copper signal chain 等连接平台半导体；SMTC / MXL 已完成分名补证据并进入 watchlist，但都仍是 proof-first / no-chase，不等同于 CRDO/ALAB 的已发现主线。
  • COHR / LITE / MTSI / FN / AAOI / GLW / ADTN / SANM 更接近 optics / DCI / scale-across follow-through：吃的是 AI 网络复杂度继续外溢到光学、DCI、coherent、制造与材料层。其中 COHR / LITE / GLW 已有 NVIDIA named evidence；FN / MTSI / AAOI / ADTN / SANM 仍只能写 sector / technology read-through，不能写 NVIDIA order attribution。ADTN 单独标注为 hidden optical/DCI recovery + early AI intra-DC optionality，SANM 是 AI/cloud infrastructure EMS + optical/networking manufacturing toll-taker，不是光模块/系统 pure play。
  • AEIS / NVTS / VICR / BELFB 虽然也服务 AI stack，但更该单列为 board / rack power components，不要和平台/互连半导体混成一类；BELFB 是小盘 data-center power/connectivity/magnetics 二阶候选，订单/backlog 证据增强但仍必须等 data-center/AI order dollars。

快速判断

  • CRDO Credo Technology — 直接；AEC + DSP + 光模块路线清晰，是当前最像被市场发现的互连主线之一。；一句话判断：【互连】AEC/retimer 真卡位；当前主线之一。客户集中高。
  • AAOI Applied Optoelectronics — 直接 / 高弹性；公司已披露 hyperscaler 800G/1.6T 订单与扩产计划。；一句话判断：【互连】模块高弹；订单来时爆发，但易过热也易价格战。
  • LITE Lumentum — NVIDIA named direct；advanced laser / CPO / silicon photonics buyer-backed capacity story。；一句话判断：【互连】NVIDIA multiyear agreement + multibillion purchase commitment + USD2B investment 把 LITE 证据强度上调，但高位仍 no-chase。
  • NVTS Navitas — 条件；高效率 10kW 平台与 AI PSU 参考设计贴合高压直流机房升级。；一句话判断：【供电器件】GaN/SiC 方向对，但兑现仍早。更像期权。
  • MTSI MACOM — 条件 / 偏扎实；1.6T/3.2T、铜互连与更广的 scale-across 器件升级给它提供中期需求支撑。；一句话判断：【器件】AMD 强化长期 relevance，但仍不足以把它从条件型名字直接升档。
  • AEIS Advanced Energy Industries — 条件 / 偏直接；Data Center Computing 收入高增，OCP/ORv3 供电路线与 AI 负载升级直接相关，但 5/29 跌破执行下沿后只能 hold / re-underwrite watch。；一句话判断：【供电】rack-level demand 底色更强，但 AEIS 仍缺 named program attribution，且 convert / dilution overhang 要折价。
  • VICR Vicor — 条件；如果高电流低电压供电架构继续演进，它的技术壁垒会被重估。；一句话判断：【高波动】靠近 GPU 供电有技术优势；兑现节奏波动大。
  • COHR Coherent — NVIDIA named direct；advanced optics / lasers / optical networking / silicon photonics 平台。；一句话判断：【光平台】NVIDIA multiyear agreement + multibillion purchase commitment + USD2B investment 是硬证据，但债务 / 整合 / execution 包袱没消失。
  • NOK Nokia Oyj — 直接 / 已重估；Q1 FY2026 已披露 AI & Cloud +49%、EUR 1B orders、Optical +20%，旧 telecom-only 框架不够。；一句话判断：【DCI/光网络】链条位置升级，但当前 vertical rerating 后只等回撤 / 利润上修，不追。
  • GLW Corning — NVIDIA named direct / 底层材料 / lower-beta；optical connectivity、fiber、photonics manufacturing。；一句话判断：【材料】NVIDIA partnership 把它从泛光纤 read-through 升为 direct lower-beta beneficiary，但弹性低于 COHR/LITE。
  • ADTN ADTRAN Holdings — 条件 / hidden recovery；FSP 3000、open optical、coherent、DCI 与 LiteWave800 让它进入 AI/cloud 光互连外溢链，但 AI/DCI 收入未单独披露且 DPLTA/RNCI 结构复杂。；一句话判断：【光网络】watchlist / proof-first，不追；等 USD 12.5-13.5 或客户/利润率/DPLTA 证据转强。
  • SMTC Semtech — 条件 / signal-chain hidden optionality；FY2026 Signal Integrity revenue 约 USD 322.6M、gross margin 约 65.2%，官方 800G/1.6T/3.2T optical + copper interconnect 证据已闭合；客户归因、CopperEdge litigation 和估值位置未闭合。；一句话判断：【信号链】watchlist / no-chase，等客户证明或 MA20/MA50 reset。
  • MXL MaxLinear — 高风险 / AI optical DSP turnaround；Keystone 800G PAM4 DSP 已有 active product、volume-production / unnamed hyperscale adoption language，Rushmore/Washington 支撑 1.6T roadmap；但 Keystone revenue dollars、named customer 和 Silicon Motion arbitration cap 未闭合。；一句话判断：【DSP期权】证据变硬但已抢跑，只能 watchlist / no-chase。
  • BELFB Bel Fuse Class B — 二阶 / 小盘 power-connectivity；FY2025 orders、Q1 FY2026 backlog、ITDS 与 networking/data infrastructure commentary 增强 data-center derivative 证据，但 AI revenue、客户名和 data-center order dollars 未闭合。；一句话判断：【电源连接器】进 watchlist，不追，等订单和 margin hold。
  • SANM Sanmina — 二阶 / AI-cloud infrastructure EMS toll-taker；ZT/AMD 使 rack-scale AI manufacturing 证据变硬，官方 optical/RF、PCB/backplane/cable/test 能力真实，但 optical/DCI revenue 和 named customer 仍未闭合。；一句话判断：【复杂制造】watchlist / monitor，当前 rerated 后只看回撤和证据。
