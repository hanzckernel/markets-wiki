How to read this master sheet

  • This is a cross-sector navigation table, not an absolute ranking list that compares banks, platforms, semiconductors, and pharma on one single multiple.
  • A true Buy / Hold / Sell needs to be established in each sector page first, then prioritized here across themes.
  • Intraday moves provide only weak sentiment input and are insufficient alone to change action.

Quadrant overview

  • Small dots = single companies; bubble labels = sector centers.
  • X-axis = Advantage strength = (quality_moat + growth_driver) / 2
  • Y-axis = Cost controlability = (valuation_setup + risk_control) / 2
  • Higher right and upper means stronger pros and more controllable costs; lower left means a weaker current setup.
  • Note: In the all-market chart, valuation_setup is still a relative score inside each sector basket, not a cross-sector unified multiple comparison.
  • For company-level comparison, use the per-theme charts and tables below as reference.
