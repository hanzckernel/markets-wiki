    目标不是再证明“AI 会带动半导体”，而是把最硬的交付约束拆成可验证链条：

    AI accelerator 需求 → leading-edge logic → HBM stack → CoWoS / SoIC / 2.5D / 3D packaging → substrate / interposer / TCB / hybrid bonding / inspection / probe / test / materials

    3. AT&S / Unimicron / Nan Ya PCB — substrate/FC-BGA 是最可能仍有 hidden alpha 的包内瓶颈层，但很多已 rerated，不能追高。
    4. Ajinomoto — ABF moat 真实，但集团分散，适合作为材料 reference / long-duration gate，而非简单买点。
    5. BESI / K&S — 技术重要，但当前需要证明 hybrid bonding / TCB 在 AI/HBM package 中的量产采用和收入弹性。

    反证与未知¶

    • TSMC CoWoS tightness / capacity doubling / balance timing 需要直接 transcript 复核；本页不把它作为 action trigger。
    • Samsung guidance 已强确认 memory-cycle / profit-cycle，但尚未闭合 direct customer qualification / shipment / segment-margin 证据。
    • Micron 的 H200 linkage 是 Micron-primary，不是 NVIDIA-primary。
    • TCB / hybrid bonding 的技术重要性不等于 BESI/K&S/ASMPT 各自份额确定。
    • Substrate / ABF 方向真实，但许多亚洲名字价格已明显重估；hidden alpha 取决于客户、ramp、margin 和回撤。
    • Materials / gases / wafer 是真实支撑层，但多数更适合作为 bridge/reference，不应升成 active mainline，除非出现直接 monetization。
