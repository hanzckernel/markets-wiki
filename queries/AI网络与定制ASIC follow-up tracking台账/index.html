    3. Per-ticker proof gaps 与触发器¶

    AVGO — Broadcom¶

    • 当前定位：direct custom ASIC + AI networking anchor；HOLD core / staged pullback-buy only。
    • 已闭合：Q2 FY2026 AI semiconductor revenue USD 10.8B（+143% YoY，高于 forecast）；Q3 AI semiconductor guide USD 16.0B（>200% YoY）。
    • 已部分闭合：AlphaStreet transcript 含 Q&A，管理层提到 FY2026 AI semiconductor USD 56B、FY2027 >USD 100B、six core customers、networking almost 40% of Q2 AI revenue、2026/2027 supply comfort 与 VMware acceleration。
    • 未闭合：issuer-primary transcript/Q&A 仍未取得；AlphaStreet 文本有第三方免责声明，且 Entropic/matter 等客户名转写存在噪声，customer concentration 与 program pull-forward 风险不能完全删除。
    • Upgrade：regular-session 稳定在 420-450 且 transcript/replay 没有负面 program/capacity/timing caveat，可以从 recheck 变 staged add。
    • Downgrade：Q&A 暗示大客户 program pull-forward、customer concentration 恶化、或 software/VMware cash conversion 走弱。
    • Dated action discipline（historical only）：420 recheck/buy、450 add、480 no-chase、525 trim/excess-only；远程 TradingView 待同步。

    MRVL — Marvell¶

    • 当前定位：custom silicon + switching + optical/interconnect 高弹性平台；不是冷门错杀。
    • Proof gaps：
    • data center mix 是否继续提升。
    • custom silicon ramp 是否有订单/收入延续性。
    • margin 是否不被 ramp cost 或 mix 稀释。
    • 大客户集中与 bookings 延续性。
    • Upgrade：出现 guide 上修或 data center/custom silicon 证据继续变硬，同时股价回到 125-145 研究重开区。
    • Downgrade：current high-zone 继续扩 multiple 但没有新 guide；margin 或 bookings 低于高预期。
    • Dated action discipline（historical only）：125-145 才重开；175-185 no-chase。CSCO 正向但不证明 MRVL 份额。

    ALAB — Astera Labs¶

    • 当前定位：rack-scale AI connectivity 半导体平台；scale-up 最核心，兼顾 scale-out。
    • Proof gaps：
    • CXL / Ethernet / NVLink Fusion / PCIe / UALink / Scorpio scale-up fabric switch 是否继续转成收入和客户扩散。
    • 高增长是否超过已很高的市场预期。
    • hyperscaler digest 或单一客户节奏是否影响增长曲线。
    • Upgrade：下一轮 issuer-primary 显示多协议平台收入继续加速、客户扩散更硬，且估值/价格回撤后仍有上修空间。
    • Downgrade：增长仍强但低于高预期，或 scale-up fabric 叙事没有 revenue/customer bridge。
    • Dated action discipline（historical only）：不把 ALAB 当“未涨过的 ASIC 折价票”；无 wiki 正式 TradingView 数字区，先只做 notes / proof ledger。

    CRDO — Credo¶

    • 当前定位：AEC / retimer / DSP / optical & copper interconnect silicon；market-found proof。
    • Proof gaps：
    • AEC / DSP / optical interconnect 是否继续从 product proof 走向 revenue/customer proof。
    • 客户集中与 hyperscaler capex 节奏。
    • 是否能持续高增长而不被估值先行透支。
    • Upgrade：回到 150-165 recheck 区，同时新财报证明 AEC/DSP/SerDes revenue 与客户扩散继续强。
    • Downgrade：186-210 高位只有叙事扩张、无收入/订单新证据；客户集中风险放大。
    • Dated action discipline（historical only）：150-165 recheck、166-185 hold、186-210 reduce/no-chase；CSCO 只加厚需求底色。

    ANET — Arista¶

    • 当前定位：AI Ethernet / cloud networking system platform；不是 connectivity semis。
    • Proof gaps：
    • earnings 后 expectation unwind 是否结束。
    • Q2 / backlog / AI networking demand 是否继续支撑 premium multiple。
    • Cisco 订单强劲中是否包含 share shift 对 ANET 的竞争压力。
    • Upgrade：股价在 138-156 且后续财报/订单继续给出上修证据。
    • Downgrade：跌穿 50DMA 后仍无需求/订单修复，说明不是单纯 expectation unwind，而是 growth premium 重估。
    • Dated action discipline（historical only）：138-156 add；170-180 no-chase；CSCO 是 TAM proxy 也是竞争者，不上移买区。

    NOK — Nokia¶

    • 当前定位：IP / optical / DCI networking platform；platform + DCI overlap，不再只按 old telecom。
    • Proof gaps：
    • AI & Cloud orders 是否持续转收入、利润和 FCF。
    • Optical + IP 增长是否被 Mobile / legacy 固网拖平。
    • Infinera 整合是否增强 webscale/optical/intra-DC，而非吃掉 margin。

    • Downgrade：价格高位横住但后续只有 multiple expansion；legacy/mobile 重新吞掉 Optical/AI-cloud 增量。
    • Dated action discipline（historical only）：current TV 重画为 12 / 13 / 15.5 / 17.5；旧 9.00-10.50 只作 deep-reset historical reference，旧 13.25-14.00 只作 old no-chase provenance，不再占用 live hlines。

    • 已有 read-through：Q3 FY2026 product orders +35%、networking orders >50%、data-center switching orders >40%、FY26 hyperscaler AI infra orders outlook USD 5B -> USD 9B、revenue outlook USD 3B -> USD 4B；post-call 加厚 Acacia / P200 / hyperscaler design wins。
    • Proof gaps：
    • orders 是否按 FY26/FY27 转收入。
    • Acacia >USD 1B orders、P200 scale-across wins 是否持续。
    • order growth 中 share gain / pull-forward / mix 的比例无法直接拆清。
    • Upgrade：跨厂商 issuer-primary 或第三方市场规模上修，让 TAM-upside proxy 可升级为更强行业 TAM 证据。
    • Downgrade：订单转收入不顺，或 hyperscaler AI infra outlook 反向修正。
    • Dated action discipline（historical only）：CSCO 支持 demand confidence，不机械上移 AVGO/MRVL/CRDO/ANET/COHR/FN/LITE zones。CSCO / HPE 属 chart-only signal stack，不是 HERMES remote watchlist addition。

    COHR — Coherent¶

    • 当前定位：光平台 / DCI / scale-across comparator。
    • Proof gaps：
    • 800G/1.6T、CPO、ZR/ZR+、OCS、DCI 需求是否形成持续收入和利润。
    • 债务与整合包袱是否改善。
    • AI 网络升级是否超出短周期模块出货，进入更广平台化升级。
    • Upgrade：回到 330-360 且公司级 optical/DCI 兑现更硬，债务/整合风险改善。
    • Downgrade：400-415 高位仅靠 CSCO/AMD read-through，无公司自证；债务/整合压力恶化。
    • Dated action discipline（historical only）：330-360 recheck、360-395 hold、400-415 reduce/no-chase。

    LITE — Lumentum¶

    • 当前定位：光器件平台；EML、泵浦激光、800G/1.6T、CPO 光源、scale-out / scale-across。
    • Proof gaps：
    • Q3 FY2026 强财报和 Q4 guide 后，Cloud & Networking 强度是否持续。
    • 客户资格导入与 capex 节奏。
    • price-discovery 区是否已经透支后续兑现。
    • Upgrade：回撤到 820-900，且下一轮财报继续证明 AI optics / scale-across revenue 和 margin。
    • Downgrade：1025-1100 继续上冲但没有新 proof；客户 capex 或资格导入变慢。
    • Dated action discipline（historical only）：820-900 pullback/recheck；960-1025 no-chase；1025-1100 reduce。

    FN — Fabrinet¶

    • 当前定位：高复杂度光学制造 / optical packaging / DCI 子系统代工 comparator。
    • Proof gaps：
    • datacom ongoing / ramping programs 是否持续。
    • 新 datacom customer agreements 是否转收入。
    • 客户集中和单一供应商依赖。
    • Upgrade：回到 580-620，同时 Q4 / 后续订单继续支撑 datacom duration。
    • Downgrade：700-735 高位无新增客户/订单 proof；客户集中或 program timing 出问题。
    • Dated action discipline（historical only）：580-620 recheck、640-690 hold、700-735 reduce/no-chase。FN 是复杂制造 toll-taker，不是 ASIC silicon。

    ARM — Arm¶

    • 当前定位：CPU IP / Neoverse / CSS / Total Design；IP 底座但非本轮短线受益核心。
    • Proof gaps：
    • Neoverse + CSS 是否带来更强 license / royalty / design-win monetization。
    • AI server CPU 增量是否真的向 Arm 份额倾斜；AMD EPYC 强 print 提醒 x86 仍有硬增量。
    • premium multiple 是否有足够增长缓冲。
    • Upgrade：license/royalty/CSS 证据显著加速，且估值 reset 后仍能看到 long-duration upside。
    • Downgrade：AI capex 扩张继续主要由 x86 / GPU 平台吸收，Arm 只保留远期 IP optionality。
    • Dated action discipline（historical only）：不当 ASIC beta，不因“custom silicon 相关”机械追价；current TV 四线 220 / 290 / 370 / 428 只表达 reset/no-chase/trim discipline。

    SNPS — Synopsys¶

    • 当前定位：EDA / IP 设计链 enabler；高质量但不是 ASIC beta。
    • Proof gaps：
    • backlog、license、IP/EDA revenue growth 是否能解释 premium。
    • custom silicon 项目增多是否真实转成公司级增长，而不是行业常识。
    • Upgrade：issuer-primary 显示 AI custom design / IP demand 对收入和 backlog 有可量化增量，且估值回撤。
    • Downgrade：EDA/IP 增速无法支撑 premium，或只是“设计链重要”但没有公司级 monetization。
    • Dated action discipline（historical only）：不当 catch-up trade；无正式 TV 数字区。

    CDNS — Cadence¶

    • 当前定位：EDA / IP premium enabler；和 SNPS 同属设计链，不是短期 ASIC 折价票。
    • Proof gaps：
    • EDA/IP 增速、backlog、AI/custom silicon 设计活动是否继续支持 premium。
    • premium valuation 是否已过度前置。
    • Upgrade：公司级订单/收入证明 AI custom design 拉动超预期，且价格/估值给出安全边际。
    • Downgrade：增长正常但低于 premium expectation；市场把 EDA 当作 ASIC beta 过度定价。
    • Dated action discipline（historical only）：不追；无正式 TV 数字区。

    TSM — Taiwan Semiconductor Manufacturing¶

    • 当前定位：leading-edge logic + CoWoS / SoIC advanced-packaging anchor；质量锚。
    • Proof gaps：
    • 需直接核验 transcript 中 CoWoS tightness、capacity doubling、supply-demand balance、pricing/margin 上下文。
    • 先进封装扩产是否继续是 AI accelerator 交付 gate。
    • 地缘折价、capex 强度、先进节点爬坡。
    • Upgrade：CoWoS/SoIC 证据更硬、产能/定价/毛利上下文清晰，且地缘/估值回撤提供加仓窗口。
    • Downgrade：先进封装 tightness 缓解快于预期、capex 压制 FCF/margin，或地缘折价扩大但无补偿性增长。
    • Dated action discipline（historical only）：core anchor / no-chase / pullback review；不是 hidden treasure。

    ASX — ASE Technology¶

    • 当前定位：OSAT platform / advanced packaging read-through；封测平台大厂但纯度一般。
    • Proof gaps：
    • FOCoS / 2.5D/3D / HBM-adjacent 证据如何转成 computing revenue mix。
    • advanced packaging capex ROI 和 margin 是否可持续。
    • broad semiconductor cycle 是否稀释 AI 主题。
    • Upgrade：computing / advanced packaging revenue mix 更清楚，订单与 margin 证明 ROI，且估值回撤。
    • Downgrade：只是周期反弹或 broad OSAT beta，AI/HPC 贡献无法拆分。
    • Dated action discipline（historical only）：no-chase anchor；不当纯数据中心或 ASIC catch-up。

    AMKR — Amkor¶

    • 当前定位：OSAT / advanced packaging service；2.5D/3D、SiP、硅光子/CPO 相关。
    • Proof gaps：
    • Arizona ramp、TSMC Phoenix 客户、advanced packaging 订单是否兑现。
    • capex 折旧、毛利、客户集中风险。
    • HPC/AI 与 mobile/auto/industrial mix 的稀释。
    • Upgrade：Arizona / TSMC collaboration 转为客户和收入 proof，毛利不被折旧吞掉，且估值 reset。
    • Downgrade：先进封装只是方向正确但收入/利润不显著；客户集中或 capex burden 恶化。
    • Dated action discipline（historical only）：pullback-proof；已重估，不追。

    4. Valuation / action discipline¶

    1. 不把“主题真实”自动等同“可以买”。本批多数名字已经重估。
    2. 每次升级必须同时满足：business proof + financial proof + price/valuation discipline。
    3. CSCO、AMD、Google、TSM 等 demand anchor 只能作为 read-through；除非 issuer-primary 指向单名，否则不能写成份额归因。
    4. Platform、merchant silicon、connectivity semis、optical/DCI、IP/EDA、OSAT 六层不得混用：
    5. ANET/NOK/CSCO 是平台层。
    6. AVGO/MRVL 是 custom ASIC / merchant silicon。
    7. ALAB/CRDO 是 connectivity semis。
    8. COHR/LITE/FN 是 optical/DCI comparator / manufacturing comparator。
    9. ARM/SNPS/CDNS 是 IP/EDA。
    10. TSM/ASX/AMKR 是 manufacturing / packaging read-through。
    11. 如果只有 product roadmap，没有 revenue / backlog / customer bridge，维持 watch / proof-first。
    12. 如果价格在 no-chase/reduce 区，除非新 proof 同时改变 earnings power，否则不因强 tape 追价。
