    CRWD — CrowdStrike¶

    角色：第 9 线 endpoint / cloud / identity security 结构状态：core Formal discovery state：Market-found 统一台账：科技主线研究ticker统一台账

    一句话看懂¶

    CrowdStrike 通过 Falcon 平台的 endpoint、cloud、identity、SIEM 与 incident-response 相关订阅赚钱。它在第 9 线的价值，不是拥有应用或数据本体，而是当 AI workload、non-human identity 与云工作负载进入生产后，为这些入口和权限面提供可收费的安全控制。

    产业链位置与边界¶

    CRWD primary-own AI应用生产化与数据生命周期 里的 endpoint / cloud / identity security 控制点，并与 平台科技、互联网与分发 保持平台分发相邻关系。它不是 application owner、data owner、E2 算力芯片 owner、E6 系统集成 owner，也不是 E7/E8 物理基础设施 beneficiary；这些节点的 monetization 需要分别回到各自 page 证明。

    AI 如何变成收入¶

    当企业把 agents、cloud workloads、identity plane 与 endpoint fleet 接到 Falcon 平台时，客户会通过模块扩展、platform consolidation 和 Falcon Flex 提高订阅规模。AI 只会在 attach、module mix 和续约里变成收入；total ARR、total revenue 或 broader security spend 不能自动当作 AI revenue。

    证据阶梯¶

    已证明¶

    • FY2026 ending ARR 为 USD 5.25B，同比 +24%。
    • FY2026 Q4 net new ARR 为 USD 331M，同比 +47%，为 record quarter。
    • Falcon Flex ending ARR 为 USD 1.69B，同比 +120%+。
    • 本地 2026-06-28 SEC latest-route packet 显示，此后新增本地可见文件主要为 Form 4 / 144 路由，没有更新的经营实绩披露进入本页 source set。

    公司口径¶

    • FY2027 ARR guide 为 USD 6.466B-6.516B。
    • 公司把 Falcon 描述为覆盖 GPU、agent 与 prompt layer 的 AI security platform。

    合理推断¶

    如果企业 agent、identity sprawl 与 cloud runtime 同时扩张，CrowdStrike 有机会把 endpoint、identity、cloud 与 SIEM 的 platform attach 继续做深。

    尚未证明¶

    • 公司没有单独披露 AI revenue；broad ARR 与 Falcon Flex ARR 不是自动等于 AI ARR。
    • “securing AI” 的 narrative 仍需要更细的 attach-rate、模块渗透与客户结果证明，才能拆成独立 AI monetization 线。

    价值捕获与误读边界¶

    CRWD 的价值捕获来自 platform consolidation、non-human identity 安全、cloud workload protection 与订阅扩展，而不是成为应用层或数据层 owner。最容易的误读，是把任何 AI 安全预算都直接写成 CrowdStrike 收入，或把 endpoint / identity security 混成 workflow、data-context permission 或 recovery ownership。

    风险与 kill criteria¶

    • Platform attach 放缓，或 Falcon Flex 扩张不能继续转成净新增 ARR。
    • Microsoft、PANW 等平台化竞争把 cloud / identity / SIEM 的 attach-rate 压低。
    • AI security 叙事持续增强，但公司仍不量化更具体的 adoption、retention 或 monetization 结果。
    • 客户 consolidation 周期拉长，导致增长更多来自 price / bundle，而不是真实 workload 扩张。

    当前角色¶

    CRWD 是第 9 线的 Core / Market-found endpoint / cloud / identity security owner。
